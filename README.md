🧮 Calculator Website

A simple and user-friendly calculator website built using HTML, CSS, and JavaScript.

🌐 Live Demo

 https://rishabpal21.github.io/Calculator/

✨ Features

- Basic arithmetic operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button
- User-friendly interface
- Responsive design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

calculator/
├── index.html
├── style.css
├── index.js
└── README.md

🚀 How to Use

1. Open the calculator website.
2. Enter numbers using the calculator buttons.
3. Select an arithmetic operation.
4. Press "=" to calculate the result.
5. Press "C" or the clear button to reset the calculator.
